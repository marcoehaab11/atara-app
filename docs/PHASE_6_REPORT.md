# تقرير المرحلة السادسة — الأنظمة اليومية

## ما نُفّذ

- مكافآت دخول أسبوعية: 20 عملة، تلميح، 40 عملة، تلميحان، 60 عملة، 3 تلميحات، ثم 100 عملة وصينية شاي؛ إن كانت الصينية مملوكة تتحول مكافأة اليوم السابع إلى عملات.
- تحدٍ يومي ثابت بالتاريخ المحلي، مولّد في Web Worker، دون طلب عميل أو اختلاف بين اللاعبين. مكافأة الإنجاز 50 + 10 × streak (حتى 7)، مع أفضل سلسلة محفوظة.
- معالجة الأيام الفائتة، حدود التقويم المحلي والتوقيت الصيفي، رجوع ساعة الجهاز، المطالبة المكررة، ترحيل الحفظ السابق إلى schema v3 واستئناف لوحة التحدي اليومية.
- شاشة يومية عربية وإنجليزية، تظهر تلقائيًا بعد الوصول للمستوى 5 مرة في اليوم، وزر التقويم يعيد فتحها. الرجوع من التحدي يعيد اللاعب إلى المستوى العادي نفسه.
- موسيقى اختبارية مولدة برمجيًا، وتحكم منفصل؛ يُستبعد مصدرها من بناء الإنتاج. الموسيقى التجارية ما زالت مطلوبة قبل الإطلاق.

## التحقق

- `npm test`: نجح، 93 اختبارًا عبر 8 ملفات.
- `npm run typecheck`: نجح.
- `npm run lint`: نجح.
- `npm run build`: نجح؛ أنتج حزمة الويب `dist/` مع تنبيه Vite عن حجم chunk، ولا يؤثر على نجاح البناء.
- فحص يدوي في المتصفح: فتح مركز اليوم بعد مستوى 5، مطالبة مكافأة اليوم الأول مرة واحدة (+20)، بدء تحدي 2026-09-29 ثابت، حفظ خمس حركات واستعادتها بعد إعادة التحميل، إكمال التحدي بـ26 حركة والحصول على 3 نجوم و60 عملة، منع إعادة اللعب لليوم نفسه، والعودة إلى المستوى العادي نفسه دون مكافأته مرتين.

## حدود التحقق

- قياس أداء 24 قطعة لم يُجر على هاتف Android؛ سبق قياسه على سطح المكتب فقط.
- لم يُنشأ مشروع Android أو AAB في هذه المرحلة. لا إعلانات أو مشتريات حقيقية.
